# 졸업연구 수행 기록

2026년 한동대학교 졸업연구에서 진행한 무인기 제어 연구의 담당 업무와 실물 검증 경험을 정리했습니다. 전자제어공학과 컴퓨터공학을 복수전공하며 배운 내용을 모델링, 소프트웨어 구현, 장치 연동 과정에서 함께 다룬 프로젝트입니다.

이 저장소는 채용 검토를 위한 문서형 포트폴리오입니다. 연구의 배경과 역할, 확인한 결과를 소개하며 실행 코드나 운용 지침은 포함하지 않습니다.

2026년 한동대학교에서 진행한 2인 졸업연구이며, 학위논문과 공동저자 학술대회 논문, 교내 실물 시연으로 정리했습니다. 연구 주제는 VTOL 재사용 인터셉터 드론이었습니다.

## 담당한 업무

저는 동역학 모델링과 자세제어, 센서 통신과 입력 처리, 모터 출력 연동, 실물 시험 프레임 제작을 담당했습니다. MATLAB·Simulink에서 모델의 응답을 살펴보고, 실물에서는 센서 정보와 모터 동작을 연결해 모델에서 예상한 움직임과 비교했습니다.

모터의 회전수·추력 측정과 모델링은 팀원과 함께 진행했습니다. 팀원은 기체의 CAD 설계와 3D 프린팅 제작을 맡았습니다. 각자 맡은 부분을 준비한 뒤 기체와 시험 장치를 연결하고 동작을 확인했습니다.

## 수행 과정에서 다룬 문제

모델에서 예상한 응답과 시험 장치에서 보이는 움직임이 같지는 않았습니다. 센서 입력, 소프트웨어 처리, 모터 출력, 실제 기체의 반응을 함께 살펴보며 차이가 생기는 지점을 확인했습니다. 모델의 결과만으로 실물 동작을 판단하기 어려웠고, 장치에서 관찰한 응답을 다시 모델과 비교하는 과정이 필요했습니다.

발표 준비 중에는 제어기 고장과 통신 문제도 겪었습니다. 원래 계획한 방식에만 매달리기보다 시연에 필요한 동작을 기준으로 준비를 조정했고, 교내 최종발표에서 시험 프레임에 설치한 기체의 동작을 보여 주었습니다.

## 결과와 확인 범위

교내 최종발표에서는 외란을 받은 기체가 시험 프레임의 기준 자세로 돌아오는 동작을 시연했습니다. 이 결과는 프레임에 구속된 조건에서 관찰한 실물 응답입니다. 자유비행이나 전체 유도·비행 시스템의 통합 검증을 완료한 결과로 해석하지 않습니다.

연구 내용은 학위논문과 별도의 학술대회 논문으로 정리했습니다. 학술대회 논문에는 공동저자로 참여했으며, 학회 포스터 발표는 팀원이 맡았습니다. 제가 참여한 교내 실물 시연과 학회 발표를 구분해 기록했습니다.

## 문서를 읽을 때 구분할 점

이 기록에서 개인 담당 업무는 제가 수행한 범위를, 공동 작업은 팀원과 함께 진행한 범위를 뜻합니다. 기체 제작 전체나 연구의 모든 소프트웨어를 혼자 완성했다는 의미로 쓰지 않았습니다. 구현 과정에서는 AI 코딩 도구도 활용했으며, 담당 범위와 도구의 도움 없이 모든 코드를 직접 작성했다는 주장은 구분합니다.

모델에서 확인한 응답, 시험 프레임에서 관찰한 동작, 학위논문과 학술대회 논문은 서로 다른 근거입니다. 모델과 실물의 차이를 살펴본 경험은 담당 업무에, 실제 시연에서 관찰한 내용은 결과 절에, 공동저자와 발표 이력은 아래 학술 기록에 나누어 적었습니다. 특정 시험 조건에서 관찰한 결과를 연구 전체의 완성도나 자유비행 성능으로 확대하지 않기 위해서입니다.

채용 검토에서는 맡은 업무와 팀원과의 분담, 모델과 실물 결과를 비교한 과정, 최종 시연의 확인 범위를 중심으로 읽을 수 있습니다. 이 저장소에는 실행·재현 명령을 추가하지 않고 수행 이력과 산출물의 성격을 설명합니다.
